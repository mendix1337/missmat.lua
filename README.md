# missmat — сайт (GitHub Pages + Supabase)

Настоящая версия: **статичный сайт** (работает на GitHub Pages / любом хостинге)
+ **Supabase** (бесплатная облачная база: аккаунты, лимиты, ключи).

## Плюсы
- Клиенты заходят с любой точки, 24/7, по постоянной ссылке
- Настоящая база: регистрация, вход, баны, муты, подписки, ключи активации
- Лимит «1 регистрация с IP в месяц» считается по IP клиента (внешний сервис ipify)

## Структура
```
site/
├── index.html            — лендинг
├── register.html         — регистрация (1 IP / месяц, по МСК)
├── login.html            — вход (бан/мут проверяются)
├── account.html          — кабинет: статус лицензии, LICENSE_END_UTC, активация ключом
├── admin.html            — админка: юзеры, бан/мут/подписки, генерация ключей
├── supabase-config.js    — твой URL + anon key (заполни!)
├── missmat-core.js       — общий код (Supabase-клиент, хэш, утилиты)
└── supabase-schema.sql   — схема БД (выполни в Supabase SQL Editor)
```

## Шаг 1. Создай проект Supabase
1. Зарегистрируйся на https://supabase.com (GitHub — одним кликом)
2. New project → назови (например `missmat`) → пароль БД сохрани → регион `eu-central-1`
3. Дождись готовности (~1 мин)

## Шаг 2. Выполни схему
1. В панели проекта слева: **SQL Editor → New query**
2. Вставь содержимое `supabase-schema.sql`
3. Run (▶) — создадутся таблицы и админ-аккаунт

## Шаг 3. Вставь ключи в supabase-config.js
1. **Settings → API**
2. Копируй **Project URL** → в `SUPABASE_URL`
3. Копируй **anon public** → в `SUPABASE_ANON_KEY`
4. Сохрани файл

## Шаг 4. Заливка на GitHub Pages
1. Создай репозиторий на GitHub
2. Залей содержимое папки `site/` (без sub-папок)
3. Settings → Pages → Source: `main` / root → Save
4. Сайт откроется на `https://твойник.github.io/репозиторий/`

## Ключи активации (для луа)
1. В админке нажми **Сгенерировать ключ** (выбери количество дней)
2. Выдай ключ покупателю (в Discord)
3. Покупатель в кабинете вводит ключ → активируется подписка
4. В кабинете появляется число `LICENSE_END_UTC` — вставить в `missmat.lua`:
   ```lua
   local LICENSE_END_UTC = 1798765140
   ```
5. Луа перестаёт загружаться после этой даты (по МСК)

## ⚠️ Важно
- `anon key` безопасен в клиенте (это и есть смысл Supabase anon — клиентский доступ)
- Пароли хэшируются SHA-256 с солью на клиенте (демо-уровень). Для серьёзной защиты
  перенеси авторизацию в **Edge Functions** (Supabase).
- Политики RLS сейчас открытые (для простоты). Перед продакшеном закрой их и отдай
  через RPC/Edge Functions.
- Лимит по IP зависит от ipify (бесплатный, без ключа).
